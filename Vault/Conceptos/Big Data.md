# Big Data

## Definición

Conjunto de datos cuyo volumen, velocidad y variedad superan la capacidad de las herramientas tradicionales de gestión, requiriendo tecnologías especializadas de almacenamiento y procesamiento distribuido.

## Resumen Personal

Relacioné este concepto con los datos no estructurados: buena parte de lo que hace 'grande' al Big Data es justamente la enorme cantidad de texto, imágenes y video generado por usuarios cada segundo.

## Importancia

Impulsa el desarrollo de nuevas herramientas de visualización capaces de resumir millones de registros en paneles comprensibles para un tomador de decisiones.
