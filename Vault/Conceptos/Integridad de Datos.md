# Integridad de Datos

## Definición

Propiedad que garantiza que los datos se mantienen completos, exactos y sin alteraciones no autorizadas a lo largo de todo su ciclo de vida, desde la captura hasta el análisis final.

## Resumen Personal

Relacioné este concepto con el control de versiones en GitHub: así como versionamos código, también deberíamos poder rastrear cambios en los datos para asegurar su integridad.

## Importancia

Sin integridad, los resultados de un análisis pueden ser cuestionados o directamente inválidos, afectando la credibilidad de toda una organización.
