# Interactividad

## Definición

Capacidad de una visualización de datos de responder a las acciones del usuario (filtrar, hacer zoom, explorar detalles al pasar el cursor), permitiendo una exploración personalizada de la información más allá de una imagen estática.

## Resumen Personal

Al revisar dashboards públicos reales noté que la interactividad cambia completamente la experiencia: un mismo conjunto de datos se siente mucho más útil cuando el usuario puede filtrar por región o periodo.

## Importancia

Permite que una misma visualización sirva a audiencias con distintos niveles de profundidad de análisis, sin necesidad de crear un gráfico distinto para cada pregunta.
