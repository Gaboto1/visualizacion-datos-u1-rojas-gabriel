# Información

## Definición

La información es el resultado de procesar, organizar o contextualizar datos, de manera que adquieren significado para quien los recibe. Es el paso intermedio entre el dato bruto y el conocimiento aplicado.

## Resumen Personal

Para mí la información es 'dato con contexto': la misma cifra puede ser irrelevante o crítica dependiendo de cómo se relacione con otras cifras, un periodo de tiempo o un objetivo de negocio.

## Importancia

La visualización de datos existe precisamente para acelerar esta transformación de dato a información, haciendo visible un patrón que en una tabla cruda pasaría inadvertido.
