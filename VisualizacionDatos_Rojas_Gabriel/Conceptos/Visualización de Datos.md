# Visualización de Datos

## Definición

Disciplina y conjunto de técnicas que permiten representar gráficamente datos cuantitativos o cualitativos con el fin de facilitar su comprensión, análisis y comunicación.

## Resumen Personal

Considero la visualización de datos como un 'traductor' entre el lenguaje de las bases de datos y el lenguaje visual que el cerebro humano procesa de forma mucho más rápida que una tabla numérica.

## Importancia

Permite detectar patrones, tendencias, outliers y relaciones que serían muy difíciles de identificar leyendo datos en bruto, acelerando la toma de decisiones.
