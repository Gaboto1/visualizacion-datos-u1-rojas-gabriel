# Herramientas de Visualización

## Definición

Software y plataformas (Power BI, Tableau, Looker Studio, Python con librerías como Matplotlib o Plotly, D3.js, Excel) utilizados para construir representaciones visuales de datos.

## Resumen Personal

Comprobé que la herramienta es solo el medio: dominar Power BI o Tableau no garantiza una buena visualización si no se aplican antes los principios de diseño de información y calidad de datos.

## Importancia

Facilitan la automatización, interactividad y actualización en tiempo real de dashboards y reportes dentro de una organización.
