# Recolección de Datos

## Definición

Conjunto de estrategias y métodos utilizados para capturar u obtener datos desde distintas fuentes: encuestas, sensores, bases de datos administrativas, APIs, redes sociales u observación directa.

## Resumen Personal

Aprendí que el método de recolección condiciona directamente la calidad y el sesgo posterior de cualquier visualización; una mala muestra jamás producirá un buen gráfico.

## Importancia

Es la primera etapa del proceso de trabajo con datos y determina el universo de análisis disponible para toda visualización posterior.
