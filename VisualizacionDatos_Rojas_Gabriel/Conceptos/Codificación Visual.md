# Codificación Visual

## Definición

Asignación de variables de datos a atributos visuales (posición, longitud, color, tamaño, forma) para representar magnitudes o categorías dentro de un gráfico.

## Resumen Personal

Este concepto me permitió entender por qué algunos gráficos 'se sienten mal' aunque no sepa explicar por qué: suelen usar canales de codificación poco precisos, como el área o el color, para representar cantidades exactas.

## Importancia

Elegir la codificación visual correcta es la decisión técnica más importante al construir cualquier gráfico, ya que determina qué tan fácil es comparar los valores representados.
