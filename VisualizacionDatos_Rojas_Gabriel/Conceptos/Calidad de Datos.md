# Calidad de Datos

## Definición

Conjunto de características (exactitud, completitud, consistencia, actualidad, integridad) que determinan si un conjunto de datos es confiable para ser usado en análisis o visualización.

## Resumen Personal

Es probablemente el concepto que más cambió mi forma de trabajar: antes de diseñar cualquier gráfico ahora me pregunto primero si los datos son correctos, completos y están actualizados.

## Importancia

Una visualización puede ser estéticamente perfecta y aun así comunicar algo falso si los datos de base tienen baja calidad; por eso es la base de toda la cadena de valor.
